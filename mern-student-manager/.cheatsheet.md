# EC2 / MERN Deployment Cheatsheet

## Local Development Commands
**Start Backend:**
```bash
cd backend
npm run dev
```

**Start Frontend:**
```bash
cd frontend
npm start
```

## AWS EC2 Setup Checklist
1. **Connect to EC2 Instance via SSH:**
   ```bash
   ssh -i /path/to/your-key.pem ubuntu@<your-ec2-ip-address>
   ```

2. **Install Node.js & npm on EC2 (Ubuntu):**
   ```bash
   curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
   sudo apt-get install -y nodejs
   ```

3. **Clone your GitHub Repo to EC2:**
   ```bash
   git clone https://github.com/Lihanitastic/TE_Prac.git
   cd TE_Prac/mern-student-manager
   ```

4. **Install Dependencies:**
   ```bash
   cd backend && npm install
   cd ../frontend && npm install
   ```

5. **Running Apps in the Background (PM2):**
   *PM2 keeps your Node.js apps running even after you close the terminal.*
   ```bash
   sudo npm install -g pm2
   cd backend
   pm2 start server.js --name "student-backend"
   pm2 save
   ```

PART 8 — INSTALL MONGODB ON MONGODB EC2
========================================================

Install dependencies:

sudo apt install gnupg curl -y


--------------------------------------------------------
IMPORT MONGODB GPG KEY
--------------------------------------------------------

curl -fsSL https://pgp.mongodb.com/server-7.0.asc | \
sudo gpg -o /usr/share/keyrings/mongodb-server-7.0.gpg \
--dearmor


--------------------------------------------------------
ADD MONGODB REPOSITORY
--------------------------------------------------------

IMPORTANT:
Ubuntu 26.04 (resolute) does NOT have official MongoDB repo.

Use Ubuntu 22.04 jammy repo instead.

Command:

echo "deb [ signed-by=/usr/share/keyrings/mongodb-server-7.0.gpg ] https://repo.mongodb.org/apt/ubuntu jammy/mongodb-org/7.0 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-7.0.list


--------------------------------------------------------
UPDATE PACKAGE LIST
--------------------------------------------------------

sudo apt update


--------------------------------------------------------
INSTALL MONGODB
--------------------------------------------------------

IMPORTANT TYPO NOTE:
Correct package name is:

mongodb-org

NOT:
mongdb-org
mongb-org

Correct command:

sudo apt install mongodb-org -y


========================================================
PART 9 — START MONGODB
========================================================

Start service:

Check status:

sudo systemctl status mongod

Expected:

active (running)

Exit status screen:
q


========================================================
PART 10 — OPEN MONGODB SHELL
========================================================

Correct command:

mongosh

NOT:
momgosh


========================================================
PART 11 — ENABLE REMOTE MONGODB ACCESS
========================================================

Open MongoDB config:

sudo nano /etc/mongod.conf


--------------------------------------------------------
CHANGE bindIp
--------------------------------------------------------

Find:

bindIp: 127.0.0.1

Change to:

bindIp: 0.0.0.0


--------------------------------------------------------
WHY?
--------------------------------------------------------

127.0.0.1
------------
Only localhost/same machine can access MongoDB.

0.0.0.0
------------
Allows remote machines to connect.


--------------------------------------------------------
SAVE NANO
--------------------------------------------------------

CTRL + O
ENTER
CTRL + X


--------------------------------------------------------
RESTART MONGODB
--------------------------------------------------------

sudo systemctl restart mongod


========================================================
PART 12 — OPEN MONGODB PORT IN AWS
========================================================

MongoDB EC2 Security Group:

Inbound Rule:

Type:
Custom TCP

Port:
27017

Source:
Backend EC2 private IP
OR backend security group

Avoid:
0.0.0.0/0


========================================================

========================================================

nc -zv 172.31.24.31 27017

succeeded

========================================================
PART 15 — MODIFY FRONTEND API URL
========================================================

Go frontend:

cd ../frontend


--------------------------------------------------------
SEARCH FOR localhost
--------------------------------------------------------

grep -rn "localhost:5000" src


--------------------------------------------------------
CHANGE API URLs
--------------------------------------------------------

FROM:

http://localhost:5000

TO:

http://BACKEND_PUBLIC_IP:5000

Example:

http://13.220.254.66:5000


--------------------------------------------------------
WHY?
--------------------------------------------------------

In browser:

localhost
means:
USER'S OWN COMPUTER

NOT EC2 server.


========================================================
PART 16 — MODIFY EXPRESS SERVER BINDING
========================================================

Open backend server:

cd ../backend

nano server.js


--------------------------------------------------------
CHANGE THIS
--------------------------------------------------------

FROM:

app.listen(PORT, () => {
    console.log(`Server running on port ${PORT}`);
});

TO:

app.listen(PORT, "0.0.0.0", () => {
    console.log(`Server running on port ${PORT}`);
});


--------------------------------------------------------
WHY?
--------------------------------------------------------

0.0.0.0 means:
listen on all network interfaces.

Without this:
EC2 may reject external traffic.

========================================================
COMMON ERRORS
========================================================


--------------------------------------------------------
ERROR:
localhost:5000 blocked by CORS
--------------------------------------------------------

CAUSE:
Frontend still calling localhost.

FIX:
Replace localhost with backend public IP.


--------------------------------------------------------
ERROR:
ERR_CONNECTION_REFUSED
--------------------------------------------------------

CAUSES:
1. backend not running
2. backend bound only to localhost
3. AWS SG port 5000 closed


--------------------------------------------------------
ERROR:
Unable to locate package mongdb-org
--------------------------------------------------------

CAUSE:
Typo.

Correct:
mongodb-org


--------------------------------------------------------
ERROR:
momgosh command not found
--------------------------------------------------------

CAUSE:
Typo.

Correct:
mongosh
